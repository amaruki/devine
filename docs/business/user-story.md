# User Stories

### US-01 — Devine’s product hook from the landing page in under 10 seconds

- **Persona:** Visitor
- **Action:** Understand Devine’s product hook from the landing page in under 10 seconds
- **Business value:** Users and judges can quickly grasp why the project is memorable and daily.dev-native

### US-02 — A Devine account with username and password

- **Persona:** Developer
- **Action:** Create and access a Devine account with username and password
- **Business value:** Devine can persist personal state securely while leaving room for OAuth providers later

### US-03 — An active daily.dev Personal Access Token

- **Persona:** Developer
- **Action:** Connect, validate, and manage an active daily.dev Personal Access Token
- **Business value:** Devine can use personalized daily.dev Public API data only when the token is usable

### US-04 — Server-persisted demo mode without a daily.dev token

- **Persona:** Developer
- **Action:** Use server-persisted demo mode without a daily.dev token
- **Business value:** Users and judges can try the product without setup while keeping repeatable demo state

### US-05 — A dashboard centered on a rubber duck companion

- **Persona:** Developer
- **Action:** View a dashboard centered on a rubber duck companion
- **Business value:** The product feels like a playful learning habit companion, not a metrics dashboard

### US-06 — Daily energy from reading, curating, discussing, and sharing daily.dev posts

- **Persona:** Developer
- **Action:** Earn daily energy from reading, curating, discussing, and sharing daily.dev posts
- **Business value:** Meaningful learning behavior becomes the core game loop

### US-07 — Health change based on daily learning progress and missed days

- **Persona:** Developer
- **Action:** See health change based on daily learning progress and missed days
- **Business value:** The duck gives visible, recoverable feedback on learning consistency

### US-08 — A 7-day seniority level and score breakdown

- **Persona:** Developer
- **Action:** See a 7-day seniority level and score breakdown
- **Business value:** The user understands their learning maturity and what behaviors shape it

### US-09 — Daily, personalized, and weekly quests

- **Persona:** Developer
- **Action:** Receive daily, personalized, and weekly quests
- **Business value:** Devine gives clear short-term actions that improve learning habits

### US-10 — Earn, store, and use power-ups

- **Persona:** Developer
- **Action:** Earn, store, and use power-ups
- **Business value:** Quest completion feels game-like while seniority remains grounded in real behavior

### US-11 — A next best action and anti-doomscrolling nudge

- **Persona:** Developer
- **Action:** Get a next best action and anti-doomscrolling nudge
- **Business value:** The user knows what to do next instead of passively consuming more content

### US-12 — Recent counted activity

- **Persona:** Developer
- **Action:** Review recent counted activity
- **Business value:** The user can understand what Devine counted and why their state changed

### US-13 — Playful duck visuals, speech bubbles, and focused micro-animations

- **Persona:** Developer
- **Action:** Experience playful duck visuals, speech bubbles, and focused micro-animations
- **Business value:** Devine feels alive, funny, and memorable inside a polished developer UI

### US-14 — Create, view, and soft-delete public static share snapshots

- **Persona:** Developer
- **Action:** Create, view, and soft-delete public static share snapshots
- **Business value:** The user can share their Devine state safely and revoke public access while preserving auditability

### US-15 — Devine fall back gracefully when daily.dev API data is unavailable

- **Persona:** Developer
- **Action:** Have Devine fall back gracefully when daily.dev API data is unavailable
- **Business value:** The app remains reliable during demos and real use

### US-16 — Raw activity events, daily pet snapshots, inventory, quests, demo state, audit events, and placeholder daily.dev ownership

- **Persona:** Developer
- **Action:** Store raw activity events, daily pet snapshots, inventory, quests, demo state, audit events, and placeholder daily.dev ownership
- **Business value:** Devine can render stable production state and recalculate scoring later when explicitly requested

### US-17 — Daily.dev Public API data within documented API constraints

- **Persona:** Developer
- **Action:** Use daily.dev Public API data within documented API constraints
- **Business value:** Devine works with official feed, post, search, bookmark, profile, tech stack, pagination, and rate-limit behavior

### US-18 — A 60-second demo path using a prepared judge demo account

- **Persona:** Hackathon judge
- **Action:** Complete a 60-second demo path using a prepared judge demo account
- **Business value:** The demo avoids signup friction and still shows the production account-based flow

### US-19 — Devine with production-grade safety, retention, and reliability

- **Persona:** Developer
- **Action:** Use Devine with production-grade safety, retention, and reliability
- **Business value:** The MVP is suitable for deployed usage, not only a local hackathon prototype

### US-20 — Prepared judge demo accounts

- **Persona:** Superadmin
- **Action:** Provision and reset prepared judge demo accounts
- **Business value:** The app owner can keep the 60-second hackathon demo reliable without manual database edits

### US-21 — Recover account access using an optional email

- **Persona:** Developer
- **Action:** Recover account access using an optional email
- **Business value:** Users who choose to add email can regain access without losing their Devine state

### US-22 — Daily activity evaluated in my locale

- **Persona:** Developer
- **Action:** Have daily activity evaluated in my locale
- **Business value:** Daily caps, health, quests, and seniority windows match the user’s expected day boundary
